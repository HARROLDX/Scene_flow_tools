# 错误经验与重要版本

## 坐标系重复翻转

`vae_metric_*` 已与 `T_cam2end-zero.json` 的相机输入约定一致。若额外乘 `diag([1, -1, -1])`，会导致部分任务轴向反转。正确链路是直接计算 `R_cam2zero @ ee_delta_model`。

## 固定点集合被逐帧替换

轨迹定义依赖首帧末端像素集合。逐帧重新应用 mask 会改变跟踪对象与统计集合；当前实现必须对所有时刻使用 `M0`。

## 重要可用版本

暂无由本地数据重新验证并登记的稳定里程碑。历史 `green_tray / sequence 0` smoke test 见 `点流工具包使用说明.md`。
